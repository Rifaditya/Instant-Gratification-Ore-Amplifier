# Perintah (/oreamp Commands)

- `/oreamp status` — Menampilkan status aktif dan pengganda saat ini
- `/oreamp get global` — Melihat pengganda global
- `/oreamp get <ore_id>` — Melihat pengganda efektif untuk bijih tertentu
- `/oreamp set global vanilla <value>` — Mengatur pengganda global Vanilla (1-1000)
- `/oreamp set <ore_id> <value>` — Mengatur pengganda bijih spesifik (0-1000)
- `/oreamp reload` — Memuat ulang konfigurasi dari file JSON
- `/oreamp reset` — Mengembalikan semua pengaturan ke default pabrik
