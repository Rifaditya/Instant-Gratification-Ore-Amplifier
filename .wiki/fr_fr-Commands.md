# Commandes (/oreamp Commands)

- `/oreamp status` — Affiche l'état et les multiplicateurs actifs
- `/oreamp get global` — Affiche les multiplicateurs globaux
- `/oreamp get <ore_id>` — Affiche le multiplicateur pour un minerai spécifique
- `/oreamp set global vanilla <value>` — Définit le multiplicateur Vanilla
- `/oreamp set <ore_id> <value>` — Définit le multiplicateur d'un minerai
- `/oreamp reload` — Recharge la configuration depuis le fichier JSON
- `/oreamp reset` — Réinitialise toutes les valeurs par défaut
