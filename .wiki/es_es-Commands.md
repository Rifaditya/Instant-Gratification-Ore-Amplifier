# Comandos (/oreamp Commands)

- `/oreamp status` — Muestra el estado y multiplicadores activos
- `/oreamp get global` — Muestra los multiplicadores globales
- `/oreamp get <ore_id>` — Muestra el multiplicador efectivo de un mineral
- `/oreamp set global vanilla <value>` — Establece el multiplicador global de Vanilla
- `/oreamp set <ore_id> <value>` — Establece el multiplicador de un mineral
- `/oreamp reload` — Recarga la configuración desde el archivo JSON
- `/oreamp reset` — Restablece todos los valores a los predeterminados
