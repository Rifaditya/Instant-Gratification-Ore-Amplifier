## 📋 Основные правила GameRules

| Правило | Название | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `ig:ore_vanilla_global` | Vanilla Ore Fallback Multiplier (%) | **200** | Глобальный множитель ванильных руд (2.0×) |
| `ig:ore_modded_global` | Modded Ore Multiplier (%) | **120** | Глобальный множитель для руд из модов (1.2×) |
| `ig:ore_vein_size_multiplier` | Ore Vein Size Multiplier (%) | **100** | Множитель размера жил в блоках (100–500%) |
