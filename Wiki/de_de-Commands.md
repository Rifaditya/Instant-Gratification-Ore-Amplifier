# Befehle (/oreamp Commands)

- `/oreamp status` — Status und aktive Multiplikatoren anzeigen
- `/oreamp get global` — Globale Multiplikatoren abfragen
- `/oreamp get <ore_id>` — Multiplikator für ein bestimmtes Erz abfragen
- `/oreamp set global vanilla <value>` — Globalen Vanilla-Multiplikator setzen
- `/oreamp set <ore_id> <value>` — Multiplikator für bestimmtes Erz setzen
- `/oreamp reload` — Konfiguration neu laden
- `/oreamp reset` — Alle Werte zurücksetzen
