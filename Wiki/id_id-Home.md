# ⛏️ Pengganda Bijih (Ore Amplifier)

> **Menggandakan generasi bijih Vanilla dan Mod (jumlah urat dan ukuran urat bijih).**
> Dapat dikonfigurasi sepenuhnya melalui GameRule, perintah dalam game, menu YACL GUI, dan file JSON.
> Bagian dari **Instant Gratification Collection** oleh **Dasik (Rifaditya)**.
