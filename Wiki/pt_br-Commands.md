# Comandos (/oreamp Commands)

- `/oreamp status` — Exibe o status e multiplicadores ativos
- `/oreamp get global` — Consulta multiplicadores globais
- `/oreamp get <ore_id>` — Consulta multiplicador de um minério específico
- `/oreamp set global vanilla <value>` — Define multiplicador global Vanilla
- `/oreamp set <ore_id> <value>` — Define multiplicador de um minério
- `/oreamp reload` — Recarrega configurações do arquivo JSON
- `/oreamp reset` — Redefine todos os valores para o padrão
