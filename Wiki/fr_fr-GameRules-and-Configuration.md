# Règles de jeu et configuration (GameRules & Configuration)

| Règle | Nom | Valeur par défaut | Description |
| :--- | :--- | :--- | :--- |
| `ig:ore_vanilla_global` | Vanilla Ore Fallback Multiplier (%) | **200** | Multiplicateur global pour les minerais Vanilla (2.0×) |
| `ig:ore_modded_global` | Modded Ore Multiplier (%) | **120** | Multiplicateur global pour les minerais de mods (1.2×) |
| `ig:ore_vein_size_multiplier` | Ore Vein Size Multiplier (%) | **100** | Multiplicateur de taille des filons en blocs (100–500%) |
