# Команды (/oreamp Commands)

- `/oreamp status` — Просмотр активных множителей и состояния мода
- `/oreamp get global` — Просмотр глобальных множителей
- `/oreamp get <ore_id>` — Запрос действующего множителя для конкретной руды
- `/oreamp set global vanilla <value>` — Установка глобального множителя ванильных руд (1-1000)
- `/oreamp set <ore_id> <value>` — Установка множителя для отдельной руды (0-1000)
- `/oreamp reload` — Перезагрузка конфигурации из файла JSON
- `/oreamp reset` — Сброс всех настроек к заводским значениям
