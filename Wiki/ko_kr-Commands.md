# 명령어 목록 (/oreamp Commands)

- `/oreamp status` — 현재 전체 배율 및 모드 상태 확인
- `/oreamp get global` — 전체 배율 조회
- `/oreamp get <ore_id>` — 특정 광물의 적용 배율 조회
- `/oreamp set global vanilla <value>` — 바닐라 전체 배율 설정 (1-1000)
- `/oreamp set <ore_id> <value>` — 특정 광물 배율 설정 (0-1000)
- `/oreamp reload` — JSON 설정 파일 다시 불러오기
- `/oreamp reset` — 모든 설정을 초기값으로 리셋
