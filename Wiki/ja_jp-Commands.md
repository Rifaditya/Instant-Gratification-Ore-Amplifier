# コマンド一覧 (/oreamp Commands)

- `/oreamp status` — 現在の全体ステータスと倍率を表示
- `/oreamp get global` — 全体倍率を確認
- `/oreamp get <ore_id>` — 指定した鉱石の実効倍率を確認
- `/oreamp set global vanilla <value>` — バニラ全体倍率を設定
- `/oreamp set <ore_id> <value>` — 特定鉱石の倍率を設定
- `/oreamp reload` — JSONファイルから設定を再読み込み
- `/oreamp reset` — すべての設定を初期値にリセット
