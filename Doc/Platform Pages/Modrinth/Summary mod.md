# Ore Amplifier

Multiply ore vein frequency (count) by up to 50x. Fully configurable via GameRules for both Vanilla and Modded ores. No config files required.

## ✨ Features

- **Extreme Amplification**: Multiply **ore vein frequency** (count) by up to **50x**.
  - *Note: This increases how OFTEN ores generate, not the size of each vein.*
- **Smart Safety**: Built-in limits prevent game freezes from excessive generation.
- **Dynamic Controls**:
  - **Global Fallbacks**: Set a base multiplier for all ores (e.g., `200` = 2x).
  - **Granular Overrides**: Set specific rules for *any* ore (e.g., `Copper Ore Multiplier` = 500).
- **Readable Config**: No more valid identifiers! Rules now appear as **"Copper Ore Multiplier"** in the menu.
- **Mod Compatible**: Automatically detects and controls modded ores.

> **Note**: Uses standard `GameRules`. No config files needed!
