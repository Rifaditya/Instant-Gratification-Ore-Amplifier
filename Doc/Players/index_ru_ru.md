# ⛏️ Руководство игрока по моду Ore Amplifier (Усилитель руд)

Добро пожаловать в **Ore Amplifier**! Этот мод умножает генерацию ванильных и модифицированных руд в мире (количество жил и размер жил), предоставляя удобные инструменты настройки через игровые правила, команды и графический интерфейс.

---

## 🚀 Быстрый старт (Quick Start)

1. **Установка**: Поместите JAR-файл `ore-amplifier` в папку `.minecraft/mods`. Убедитесь, что установлены **Fabric Loader**, **Fabric API** и **Dasik Library**.
2. **Запуск**: В любых новых генерируемых чанках руды автоматически будут появляться с повышенным коэффициентом (по умолчанию для ванильных руд: **200% / 2.0x**, для руд из модов: **120% / 1.2x**).
3. **Существующие миры**: Уже сгенерированные чанки не перезаписываются автоматически. Чтобы применить множители, исследуйте новые территории или воспользуйтесь [MCA Selector](https://github.com/Querz/mcaselector) для сброса нужных чанков.

---

## ⚙️ Настройка через GameRules

В одиночной игре нажмите `Esc` $\rightarrow$ `Открыть для сети` (разрешить читы) $\rightarrow$ `Игровые правила`, найдите раздел **Усилитель руд (Ore Amplifier)**:

| Игровое правило | По умолчанию | Описание |
| :--- | :---: | :--- |
| `ig:ore_vanilla_global` | `200` | Базовый множитель для всех ванильных руд (200 = 2.0x) |
| `ig:ore_modded_global` | `120` | Базовый множитель для руд из сторонних модов (120 = 1.2x) |
| `ig:ore_vein_size_multiplier` | `100` | Множитель размера рудных жил в блоках (100%–500%) |
| `ig:ore_<namespace>_<ore>` | `100` | Индивидуальное правило для конкретной руды (переопределяет глобальное) |

## 💬 Внутриигровые команды (/oreamp)

Мод предоставляет полное дерево команд Brigadier с автодополнением:

```bash
# Просмотр текущего статуса и активных множителей
/oreamp status

# Просмотр эффективного множителя для конкретной руды
/oreamp get minecraft:diamond_ore

# Установка глобального множителя ванильных руд на 3.0x (300%)
/oreamp set global vanilla 300

# Установка множителя алмазной руды на 5.0x (500%)
/oreamp set minecraft:diamond_ore 500

# Сброс всех настроек к значениям по умолчанию
/oreamp reset

# Перезагрузка настроек из config/ore-amplifier.json
/oreamp reload
```

## 🖥️ Графический интерфейс YACL & ModMenu

При наличии модов **YACL v3** и **Mod Menu** доступен графический экран настроек (`Моды` $\rightarrow$ `Ore Amplifier` $\rightarrow$ `Настроить`):
- **Общие настройки**: Слайдеры для глобальных множителей и размера жил.
- **Индивидуальные множители**: Настройка 18 ванильных руд от 0% до 1000%.
